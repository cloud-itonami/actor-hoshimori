# actor-hoshimori — orbital-stewardship observatory actor

`actor-hoshimori` maps public orbital regimes, congestion, debris hazards, and
service dependencies to stewardship and resilience. Its canonical repository
is `cloud-itonami/actor-hoshimori`.

The actor is an observation-only Cloud Itonami observatory: it emits no precise
predictive ephemeris and operates no spacecraft. It owns no etzhayyim Charter,
Council, or organism state. Existing DID, namespace, Radicle identity, and old
GitHub URL remain compatibility identities.

Run `kbb -M:test` for the executable contract suite.
